# Brand Intel — Kura Kura Bali

Prototype of a brand-monitoring and communications dashboard for the Kura Kura Bali communications team.

- **Live:** https://brandawareness.sonigo.tech
- `prototype/` — the clickable prototype (static HTML/CSS/JS, demo data, English ⇄ Bahasa Indonesia).
- `design-system/` — Kura Kura Bali tokens + components CSS, brand guide and component preview, reusable in other projects.
- `docs/` — UX rationale and Brand24 research notes (Indonesian).

Run locally:

```bash
cd prototype && python3 -m http.server 5317 --bind 127.0.0.1
```

All data in the prototype is demo data. Logo and brand colours belong to Kura Kura Bali.
